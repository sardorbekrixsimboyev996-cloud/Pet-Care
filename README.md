# Paws & Well

A self-contained responsive website project.

## Run it

Open `index.html` directly in a browser. No installation or build step is required. The interface works locally; photography and web fonts load from the internet.

## Files

- `index.html` — page structure and project content
- `style.css` — responsive visual design
- `script.js` — search, filters, saved items, form feedback and theme control
